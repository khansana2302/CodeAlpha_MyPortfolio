# Personal Portfolio Website
CodeAlpha Frontend Development internship task.

## Technologies
HTML5, CSS3 and JavaScript.

## Sections and features
- Hero introduction, About, Skills, Projects and Contact sections
- Responsive desktop and mobile layout
- Smooth scrolling and mobile navigation menu
- Hover effects and clean project presentation
- Skills, project details and contact information

## Personalize before publishing
In `index.html`, replace `Your Name`, `YOUR NAME` and `your.email@example.com` with your own details. Only list skills you can honestly discuss.

## Run
Open index.html in a modern browser.

Suggested repository: `CodeAlpha_Portfolio`
